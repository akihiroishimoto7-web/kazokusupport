# 事業分析：RUN LIFE HIROSHIMA を収益型メディアにする

最終更新：2026-11-25（エージェント作業による）

## 1. 結論

月5万円の利益に向けて、いまいちばん効く打ち手は、新しい機能ではありません。すでにある導線に「お金が流れる蛇口」を付けることです。

サイト内の購入リンクは、すべてアフィリエイトIDが未設定（`content/affiliate.ts` が null）のため、現在のHPからの紹介料収入は構造的にゼロです。ID を入れれば、全シューズページ・比較・診断・アメブロ下書きのリンクが一度に切り替わる作りになっています。次に必要なのは、アクセス解析です。計測がないため、どのページが読まれ、どこから買われているかがわかりません。

今回の作業では、その蛇口の先にある「水源」を作りました。メーカー公式ページから集めたシューズの仕様と価格の記録です。これは時間がたつほど価値が増えるデータ（価格履歴・値下がり記録）で、検索流入の入口（比較ページ）と、アメブロのセール記事の材料を同時に生みます。

## 2. 現状の構造（2026-11-25時点）

| 領域 | 中身 | 収益との関係 |
| --- | --- | --- |
| ホーム・記事（17本） | 走ることの読み物、広島のコース、ケア | ブランドと信頼。直接の収益はない |
| シューズ研究所（26シリーズ） | 位置づけ、向く人・向かない人、買わなくていい理由 | 購入導線の中心。ただし大半が仕様未確認で検索非登録だった |
| シューズDB（今回新設） | 5ブランド18モデルの公式仕様・価格・根拠の原文 | 検索登録の条件を満たすページを12シリーズに増やした |
| 比較（今回拡張） | 3足比較ツール＋「AとBの違い」25ページ | 指名検索（「ゴースト18 ペガサス42 比較」など）の入口 |
| 診断（今回拡張） | 走力・用途・悩み・好み・足幅・予算の6問 | 予算を公式価格で判定、前の世代のセールを提示 |
| アメブロ連携 | HP←RSS（関連記事の自動表示）、HP→アメブロ下書き（今回新設、utm付き） | アメブロ側の Ameba Pick が実際の収益源 |
| Instagram | 世界観のみ（商品・販売は扱わない） | 収益化しない（方針） |

## 3. 収益の考え方（試算の型）

数値はすべて仮定です。料率は各ASP・ショップの最新条件で確認してから使ってください（**要確認**）。

月の利益 ＝ 送客したクリックのうち購入された件数 × 平均購入額 × 料率

シューズの平均購入額を1万5千円と置くと、月5万円に必要な紹介対象の売上は、料率4%なら約125万円（約83足）、料率8%なら約62万5千円（約42足）です。購入率（クリックのうち買われる割合）を仮に3〜5%とすると、必要な購入先クリックは月に約800〜2,800回になります。

ここから逆算すると、目標は「月に数千回、購入先へのクリックが起きるサイト」です。そのための現実的な道筋は次の3本です。

1. **検索流入（HP）**：比較ページとモデルページ。公式仕様が載ったページだけを検索登録し、数を増やす。
2. **アメブロ（Ameba Pick）**：値下がりまとめとモデル記事を、データから下書き生成して定期投稿。アメブロ内の回遊と検索の両方を取る。
3. **前の世代のセール**：公式ストアで40〜70%引きの旧モデルが実在する（2026-11-25確認、例：Saucony RIDE 18 が通常22,000円→6,600円）。「最新でなくていい」という方針と一致し、読者の得にもなる。

## 4. 優先順位

| 優先 | 打ち手 | 必要なもの | 承認 |
| --- | --- | --- | --- |
| 1 | アフィリエイトIDの設定（楽天・Amazon・バリューコマース） | 運営者のアカウント登録（無料） | 要：アカウント作成は運営者 |
| 2 | アクセス解析（Vercel Web Analytics または GA4） | 設定のみ。Vercel は無料枠あり、超過は有料 | 要：有料化の可能性 |
| 3 | 今回の変更の本番公開 | このブランチのPRのマージ | 要：本番公開 |
| 4 | 価格の定期収集（週1） | `npm run shoes:collect`（エージェント運用） | 不要（読み取りのみ） |
| 5 | アメブロへの定期投稿（週1：値下がりまとめ、月数本：モデル記事） | 下書きは自動、投稿は手作業 | 投稿は運営者 |
| 6 | 自動取得できない4社（ASICS・adidas・HOKA・NB）の仕様 | 手作業での公式確認、または取得方法の見直し | 不要 |
| 7 | 独自ドメイン | 年数千円程度（**要確認**） | 要：有料 |
| 8 | 実際に履いたレビュー | 運営者の体験 | — |

## 5. やらないこと

- 紹介料の高さで順位や評価を変えること（診断・比較のロジックに価格以外の収益情報は入っていません）
- 公式に書かれていない数値を推測で埋めること（未確認は「未確認」と表示）
- Instagram での商品紹介
- 自動でのブログ・SNS投稿

## 6. 計測すべき指標（解析導入後）

- 検索から入ったページ（比較ページ・モデルページの表示回数とクリック率）
- 購入先リンクのクリック数（ページ別）
- アメブロからHPへの流入（`utm_source=ameblo` で識別できるようにしてあります）
- 診断の完了数と、結果からのクリック

# 編集方針：3つの媒体の役割

> 美しいから訪れる。役立つから信頼する。そして、また訪れたくなる。

| 媒体 | 役割 | 扱うもの | 扱わないもの |
| --- | --- | --- | --- |
| Instagram | 感性と世界観 | 広島のランニング風景、朝と夕暮れの光、走る心地よさ、仲間との時間、リフティング瞑想、心を整えること、短い言葉、写真とリール | 商品紹介、セール速報、アフィリエイト誘導、ランキング、購入を促す投稿、PR色の強いカルーセル、商品記事の転載 |
| アメブロ | 専門性と収益 | シューズレビュー・比較、セール、補給ジェル比較、用品、ケガ予防、市民ランナー向けの実用情報（Ameba Pick を活用） | 正確性の確認できない情報、煽る表現 |
| ホームページ | ブランドの中心 | 写真と編集コンテンツ。実用情報は「シューズ」「補給と道具」などの独立したセクションから | トップページを広告や商品カードで埋めること |

## 振り分けの手順

1. 企画を `content/editorial.ts` に登録し、媒体ごとに公開可否を決める
2. 商品・セール・アフィリエイトに関わる企画は `commercial: true`。**Instagram は必ず "none"**
3. HPの記事は frontmatter の `channels` で上書きできる（初期値はカテゴリーごと：`lib/articles.ts` の `DEFAULT_CHANNELS`）
4. `npm run channels` で一覧を確認、`npm run validate` でルール違反を検出

## Instagram に投稿するとき

- 商業的な一文（「プロフィールのリンクから」「今ならセール」など）を自動で付けない
- HPの Instagram セクションには、写真だけを表示し、キャプションや購入導線は出さない
- 手で登録する場合は `content/instagram.ts`、公式APIの場合は Vercel の環境変数 `INSTAGRAM_ACCESS_TOKEN`

## アメブロに書くとき

- 広告（PR）表記を記事の冒頭に明記する
- 「買わなくていい人」にも役立つ内容にする
- HPの関連ページ（シューズ研究所・コース図鑑など）へリンクする
- HPのトップには最新記事のタイトル・日付・冒頭だけが、RSSから自動で表示されます

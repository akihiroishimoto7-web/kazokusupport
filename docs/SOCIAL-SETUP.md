# Instagram・アメブロ連携の設定

設定するまで、トップページとシューズ研究所の連携セクションは表示されません（空の枠や偽の投稿は出しません）。

## アメブロ（自動更新・設定は1か所）

1. `content/social.ts` の `amebaId` に、アメブロのIDを書く
   例：ブログのURLが `https://ameblo.jp/abcdef/` なら `amebaId: "abcdef"`
2. 公開すると、アメブロ公式のRSS（`https://rssblog.ameba.jp/abcdef/rss20.xml`）から最新記事を1時間ごとに自動で取得します

表示するのは、RSSに含まれる **タイトル・公開日・本文の冒頭**と、本文に画像があればその画像だけです。
RSSにアイキャッチ画像の項目はないため、記事ページから画像を抜き出すこと（スクレイピング）はしていません。

## Instagram

### A. 手で登録する（すぐ使える・おすすめ）

1. `content/social.ts` の `username` に、ユーザーネーム（@なし）を書く
2. 投稿した写真を `public/instagram/` に保存
3. `content/instagram.ts` に、写真・投稿URL・説明（代替テキスト）を追加
   → 「この投稿をHPに載せたい」と AI に頼めば追加できます

### B. 公式APIで自動更新する

条件：Instagram の **プロアカウント**（ビジネスまたはクリエイター）

1. Meta for Developers でアプリを作成し、「Instagram API with Instagram Login」を追加
2. 自分のアカウントでログインし、**長期アクセストークン**を発行（有効期限は約60日）
3. Vercel のプロジェクト（kazokusupport-u8zk）の Settings → Environment Variables に
   `INSTAGRAM_ACCESS_TOKEN` として保存（**ソースコードには書かない**）
4. 再デプロイすると、最新の投稿が1時間ごとに自動で表示されます

長期アクセストークンは約60日で切れます。期限が切れると、自動で A（手で登録した投稿）の表示に戻ります。
期限前に更新する場合は、Meta のトークン更新（`refresh_access_token`）で新しいトークンを発行し、環境変数を差し替えてください。

## サイトに表示されるもの

| 媒体 | 場所 | 表示するもの | 表示しないもの |
| --- | --- | --- | --- |
| Instagram | トップページ | 写真（大1・小4）、元の投稿へのリンク | キャプション、いいね数、購入の導線 |
| アメブロ | トップのシューズの章（3件）、シューズ研究所（6件） | タイトル、日付、本文の冒頭、本文中の画像 | 推測した情報 |

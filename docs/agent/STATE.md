2. **値下がりまとめの下書き**：収集のあと `npm run ameblo:drafts`
3. **前の世代の追加**：Nike（Pegasus 41・Vomero 17）、On（Cloudmonster 2）、ミズノ（WAVE RIDER 29・WAVE INSPIRE 21）が公式ストアに残っていれば `targets.json` に previous で追加

5. **重量の計測サイズ**：On・サッカニーは公式ページに計測サイズの記載が見つからなかった（「計測サイズの記載なし」と表示）。記載のある公式資料が見つかれば追記
6. **ミズノのドロップ**：商品ページに記載なし。公式カタログ等に記載があれば追記
7. **Vomero 18 の通常価格**：2026-11-25 はセール表示で通常価格が出ていなかった。手作業で確認した 2026-11-22 のワイド版の通常価格（17,600円）を表示中。次回の収集で通常価格が取れれば自動で置き換わる
8. 比較ページが増えたら、検索での表示状況（解析導入後）を見て、読まれる組み合わせの説明を厚くする

## 判断の記録（なぜそうしたか）

- **自動取得した値を「確認済み」として表示する根拠**：値ごとに公式ページの該当行を原文のまま保存し（evidence）、テストで「根拠の行に値が含まれていること」「厚さの差とドロップが一致すること」を検査している。ページには「公式ページの記載（原文）」として開示している
- **検索登録の条件**：レビュー済み、または現行モデルの重量と価格を公式で確認できたページだけ（`lib/shoe-db.ts` の `isIndexableShoe`）。中身の薄いページを登録しないため
- **比較ページの組み合わせ**：公式確認済みのシリーズ同士で、用途が2つ以上重なるものだけ。重量は計測サイズが同じときだけ差を書く（Nike は28cm、ブルックス・ミズノは27cm で単純比較できない）
- **予算判定**：公式ストアで確認できた価格だけを使う。価格不明のシリーズは加点も減点もしない。予算内に現行がなく前の世代があれば、前の世代を提示する
- **Playwright をリポジトリの依存に入れていない**：Vercel のビルドを重くしないため。収集はクラウド環境（導入済み）で実行する

## なぜ、歩くことから始めるのか

運動から離れていた体に、いきなり走る負荷をかけると、筋肉や関節、とくに膝や足首に負担がかかりやすくなります。心臓や肺は数週間で慣れてきても、筋肉や腱、骨が慣れるには、もう少し時間がかかると言われています。

だから最初の1週間は、走ることよりも「決まった時間に外に出る」ことを目標にします。

## 1週間の目安

あくまで一つの例です。体調や生活に合わせて、自由に変えてください。

| 日 | 内容 |
| --- | --- |
| 1日目 | 20分ほど、少し早足で歩く |
| 2日目 | 休み |
| 3日目 | 20〜25分歩く。余裕があれば、途中で30秒だけ軽く走ってみる |
| 4日目 | 休み |
| 5日目 | 25分歩く。30秒の軽いジョグを2〜3回まぜる |
| 6日目 | 休み、または軽い散歩 |
| 7日目 | 振り返り。疲れや痛みが残っていないか確かめる |

休みの日は、さぼりではありません。体が負荷に慣れていくための、大切な時間です。

## 歩くときに意識したいこと

- 背すじを軽く伸ばし、視線は少し先へ
- 腕は自然に、後ろに引くように振る
- 呼吸が少し弾むくらいの早さで

「少しきつい」と感じたら、ペースを落としてください。最初の1週間に、がんばりは必要ありません。

## こんなときは、休む

:::caution 痛みは、止まる合図
膝や足首、すねなどに痛みが出たら、その日は無理をせず休みます。数日たっても痛みが引かない、腫れている、歩くのもつらい、といった場合は、医療機関に相談してください。
:::

## 1週間が終わったら

「外に出る」ことに少し慣れてきたら、次は歩きと走りを組み合わせた1か月へ進みます。急がなくて大丈夫です。もう1週間、同じ内容を繰り返すのも、立派な選択です。
